# Happy — локальный русскоязычный бот

Проект команды **mk studio** для конкурса **«Тьюринг Арена» (IT FEST 2026, Astana IT University)**.

Бот работает **полностью офлайн** на ноутбуке, отвечает **только текстом и только по-русски**,
укладывается в **300 символов** и **45 секунд** (фактически — миллисекунды).

Персона: **Мирас, 17 лет, Астана** — родился и вырос в городе, поступил в AITU по ЕНТ,
первый курс. Говорит коротко, по-человечески, иногда с «)» и «не знаю».

Главная идея: не «самый умный» бот, а **самый похожий на человека**. Поэтому в проекте
три равноправных слоя — качество ответа, человеческий голос и надёжность.

---

## 1. Соответствие регламенту

| Требование организаторов | Как выполнено |
|---|---|
| Бот разработан участниками | весь код в репозитории, модели обучаются с нуля |
| **Запрещены готовые LLM, их веса и внешние API** | нет ни одного предобученного веса; нет `transformers`, нет API-вызовов |
| Полностью локальная работа без интернета | сеть не используется ни на одном шаге; `scripts/preflight.py` физически запрещает сокеты |
| Только русский язык, только текст | русская нормализация, русские корпуса, plain text |
| Ответ ≤ 300 символов | жёсткий обрез по границе слова + целевая длина 90–220 |
| Ответ ≤ 45 секунд | p50 ≈ 1 мс, p95 ≈ 2 мс на CPU, без GPU |
| Нельзя вручную править/выбирать ответ | оператор только вводит вопрос |

**Происхождение весов.** BPE-словарь, классификатор интентов и bi-encoder обучаются
с нуля на курируемом корпусе и открытых русских диалогах. Предобученные эмбеддинги,
языковые модели и чужие веса не используются. Метрики — в `artifacts/training_metrics.json`,
процедура — в `scripts/train.py`.

## 2. Как работает ответ

```
вопрос
  │
  ├─ 1. нормализация: ё→е, лемматизация pymorphy3, ключевые слова
  │
  ├─ 2. маршрутизация
  │      ├─ решатель: арифметика, проценты, буквы, даты, последовательности
  │      ├─ защита персоны: «ты бот?», «докажи, что человек»
  │      └─ поиск по базе
  │
  ├─ 3. гибридный поиск
  │      свой BM25 (инвертированный индекс) + косинус по векторам bi-encoder
  │      → 0.55 * BM25 + 0.45 * cosine, затем гейт по покрытию терминов
  │
  ├─ 4. выбор ответа
  │      высокая уверенность → готовый человеческий ответ из базы
  │      средняя          → ответ + осторожная формулировка
  │      низкая           → «не знаю» по-человечески + встречный вопрос
  │
  ├─ 5. персона и память
  │      один характер, антиповтор в рамках раунда
  │
  └─ 6. humanizer
         убрать «книжный» стиль, строчные, «)», редкая опечатка,
         длина ≤ 300, человеческая пауза при печати
```

Ключевой принцип: **бот никогда не возвращает пустой ответ**. Два пустых ответа
в одном испытании — снятие, поэтому последний слой — гарантированная фраза.

## 3. Быстрый старт

```bash
# 1. окружение (Python 3.11–3.12)
python3 -m venv .venv
source .venv/bin/activate

# 2a. полный гибрид (BM25 + своя нейросеть)
pip install -r requirements-dense.txt

# 2b. или только BM25-режим, без torch
pip install -r requirements.txt

# 3. проверить офлайн-режим
python scripts/preflight.py

# 4. терминал
python run_cli.py

# 5. локальный веб-интерфейс
python run_ui.py
```

`http://127.0.0.1:8000/` — тёмный интерфейс без CDN и внешних шрифтов.
Галочка «человеческая пауза» добавляет задержку печати 2–9 секунд.

> После установки зависимостей интернет не нужен. В `run_ui.py` нет ни одного
> внешнего ресурса — ни шрифтов, ни CDN, ни аналитики.

Если `torch` не установлен или артефакты не совпадают по размеру с корпусом,
бот автоматически работает в BM25-режиме. Это не ошибка, а страховка для сцены.

## 4. Обучение

Всё обучение — **на Kaggle**, с автопушем в Hugging Face после каждой эпохи.
Подробная инструкция: **[KAGGLE.md](KAGGLE.md)**.

```bash
# локальный smoke-тест (30 секунд, без пуша)
python scripts/train.py --smoke --out artifacts_smoke --no-push

# полный прогон (так его запускает Kaggle)
python scripts/train.py --out artifacts --run-name kaggle-main \
    --hf-repo mkstudio/happy-artifacts --push-every-epoch --resume
```

Что обучается:

| Компонент | Архитектура | Артефакт |
|---|---|---|
| Токенизатор | BPE с нуля, 2 000 слияний | `vocab.json` |
| Классификатор интентов | BiLSTM + attention pooling | `intent_model.pt`, `labels.json` |
| Bi-encoder | Siamese BiLSTM, mean+max pooling, 128-d | `bi_encoder.pt` |
| Поиск | свой BM25 + матрица векторов | `bm25.pkl`, `corpus_vectors.npy` |

Никаких `transformers`, `sentence-transformers`, `word2vec` и скачанных весов.

### Почему Kaggle, а не локально

Модели крошечные и обучаются за минуты, но Kaggle даёт воспроизводимый облачный
прогон и независимый бэкап. Локальный запуск оставлен только для smoke-теста:
на сцене ноутбук не должен тратить время на обучение.

### Почему ничего не теряется

Каждая эпоха: атомарный чекпоинт → сразу пуш в HF (`{run}/checkpoints/...`).
В конце: `manifest.json` с sha256 каждого файла, `latest.json` и ZIP.
`scripts/pull_model.py` скачивает и **проверяет хеши**. Если сессия умерла —
`--resume` продолжает с последней эпохи, а не с нуля.

## 7. Метрики (прогон на 1 142 записях)

| Метрика | Значение |
|---|---|
| Курируемая база | **1 142 записи / 2 403 формулировки** |
| intent accuracy (val) | **0.733** |
| contrastive loss | **0.694** |
| paraphrase Recall@1 / @5 | **0.832 / 0.929** (113 запросов) |
| p50 / p95 latency | **1.0 / 1.7 мс** |
| пустых ответов | **0** на 400 тестовых вопросах |
| red-team 300 (regression) | **70.7%** автоответов |
| holdout 100 (unseen) | **64.0%** автоответов |

`red-team 300` использовался как диагностический набор: по его провалам база
дополнялась, поэтому часть вопросов теперь пересекается с ней. Честная метрика
обобщения — отдельный `holdout_100`, который не использовался при разработке.

Низкое покрытие **не равно пустому ответу**: остальные вопросы получают
человеческое «не знаю» и встречный вопрос. Для теста Тьюринга это часто
убедительнее уверенной ошибки. Следующий шаг — расширение базы по темам,
которые чаще всего спрашивают на мок-раундах.

## 9. Почему это не LLM

- нет декодера-трансформера и генерации «из головы»;
- нет предобученных весов: словарь и эмбеддинги обучаются на нашем корпусе;
- ответ собирается из проверенной базы, факта или безопасного фолбэка;
- рантайм — numpy + pymorphy3 + собственный BM25 (+ torch для bi-encoder);
- `preflight.py` отключает сокеты и доказывает, что сеть не нужна.
