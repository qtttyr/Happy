# Тьюринг Арена — локальный русскоязычный бот

Бот для конкурса **«Тьюринг Арена» (IT FEST 2026, Astana IT University)**.
Работает **полностью офлайн** на ноутбуке, отвечает **только текстом и только по-русски**,
укладывается в **300 символов** и **45 секунд** (фактически — десятые доли секунды).

Главная идея: не «самый умный» бот, а **самый похожий на человека**. Поэтому в проекте
три равноправных слоя — качество ответа, человеческий голос и надёжность.

---

## 1. Соответствие регламенту

| Требование организаторов | Как выполнено |
|---|---|
| Бот разработан участниками | Весь код в репозитории, модели обучаются с нуля |
| **Запрещены готовые LLM, их веса и внешние API** | В проекте нет ни одного предобученного веса; нет `transformers`, нет обращений к API |
| Полностью локальная работа без интернета | Сеть не используется ни на одном шаге; `scripts/preflight.py` физически запрещает сокеты и прогоняет бота |
| Только русский язык, только текст | Русская нормализация, русские корпуса, ответ — plain text |
| Ответ ≤ 300 символов | Жёсткий обрез по границе слова + целевая длина 90–220 |
| Ответ ≤ 45 секунд | p50 ≈ 1–3 мс на CPU, без GPU |
| Нельзя вручную править/выбирать ответ | Оператор только вводит вопрос; всё остальное делает движок |

**Происхождение весов.** Все нейросети (классификатор интентов и bi-encoder) обучаются
с нуля на открытых русских диалоговых корпусах и нашем курируемом наборе. Никакие
предобученные эмбеддинги, языковые модели и веса не используются. Подробности —
в `ARCHITECTURE.md` и `training_metrics.json`.

## 2. Как работает ответ

```
вопрос
  │
  ├─ 1. нормализация: ё→е, лемматизация pymorphy3, ключевые слова
  │
  ├─ 2. маршрутизация
  │      ├─ решатель: арифметика, проценты, буквы, даты, последовательности
  │      ├─ защита персоны: «ты бот?», «докажи, что человек»
  │      └─ поиск по базе
  │
  ├─ 3. гибридный поиск
  │      BM25 (свой инвертированный индекс) + косинус по эмбеддингам bi-encoder
  │      + буст по интенту и теме
  │
  ├─ 4. выбор ответа
  │      высокая уверенность → готовый человеческий ответ из базы
  │      средняя          → ответ + осторожная формулировка
  │      низкая           → «не знаю» по-человечески + встречный вопрос
  │
  ├─ 5. персона и память
  │      один и тот же характер, антиповтор в рамках раунда
  │
  └─ 6. humanizer
         убрать «книжный» стиль, строчные буквы, «)», редкая опечатка,
         длина ≤ 300, человеческая пауза при печати
```

Ключевой принцип: **бот никогда не возвращает пустой ответ**. Два пустых ответа в
одном испытании — снятие с конкурса, поэтому последний слой — гарантированная фраза.

## 3. Быстрый старт (macOS / Linux)

```bash
# 1. окружение (Python 3.11–3.12)
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 2. собрать индекс (один раз)
python scripts/build_index.py

# 3. проверить офлайн-режим
python scripts/preflight.py

# 4. терминал
python run_cli.py

# 5. локальный веб-интерфейс (без CDN и внешних шрифтов)
python run_ui.py
```

Открывается `http://127.0.0.1:8000/`. Галочка «человеческая пауза» добавляет
задержку печати, чтобы ответ не выглядел мгновенным.

> После установки зависимостей интернет не нужен. В `run_ui.py` нет ни одного
> внешнего ресурса — ни шрифтов, ни CDN, ни аналитики.

## 5. Данные

| Источник | Назначение | Лицензия |
|---|---|---|
| Собственный курируемый набор (`data/curated_qa.jsonl`) | основные ответы, голос, контрольные вопросы | авторский |
| Открытые русские диалоговые корпуса | обучение bi-encoder, расширение поиска | MIT / CC |
| SberQuAD | проверка фактических вопросов | см. карточку датасета |

Сырые диалоги **не выдаются как ответы**: они проходят фильтр длины, языка,
ссылок, мата и личных данных, а итоговый ответ всегда проходит humanizer.

---

## 6. Почему это не LLM

- нет декодера-трансформера и генерации текста «из головы»;
- нет предобученных весов — словарь и эмбеддинги обучаются на нашем корпусе;
- ответ собирается из проверенной базы, факта или безопасного фолбэка;
- весь рантайм — numpy + pymorphy3 + собственный BM25, работает на CPU;
- `preflight.py` отключает сокеты и доказывает, что сеть не нужна.
